프로젝트 분석 시스템 · 프로토타입 v0.3
======================================

프로젝트 폴더를 불러와 [분석 시작]을 누르면, 어떤 시스템인지와
DB 테이블·메뉴·화면·배치의 관계를 정리해 보여 줍니다.
소스는 이 PC 안에서만 읽고, 어디로도 보내지 않습니다. 인터넷이 없어도 됩니다.


1. 실행 방법
-------------
[데스크톱 앱]
  1) ProjectAnalyzer-…-win.zip 압축을 풉니다. (설치 필요 없음, 관리자 권한 필요 없음)
  2) 폴더 안의 ProjectAnalyzer.exe 를 실행합니다.
  3) 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
     (코드 서명을 하지 않은 프로토타입이라 나오는 안내입니다)

[HTML 파일]
  1) project-analyzer.html 을 Edge 또는 Chrome으로 엽니다.
  2) 폴더를 고르면 브라우저가 "파일을 업로드할까요?"라고 묻습니다.
     실제로 업로드되지 않고, 이 브라우저 안에서만 읽습니다. [업로드]를 누르면 됩니다.
  * 소스가 수만 개인 큰 프로젝트는 데스크톱 앱이 더 빠릅니다.


2. 사용 순서
-------------
  1) [폴더 열기]를 누르거나 프로젝트 폴더를 창에 끌어다 놓습니다.
  2) 불러오기 확인 화면에서 분석에서 뺄 폴더를 체크 해제하고 [분석 시작]을 누릅니다.
  3) 결과 요약에서 시스템 유형, 사용 언어·DB, 개수, 확인 필요 항목을 봅니다.
  4) 왼쪽 트리(DB 테이블 / 메뉴 / 화면 / 배치)에서 항목을 누르면 상세가 나옵니다.
     - 화면: 관련 파일, 사용 테이블(CRUD), 호출 흐름
     - 테이블: 컬럼, 이 테이블을 쓰는 화면·배치
     - 메뉴: 하위 화면과 테이블 합계
     - 배치: 실행 주기, 실행 흐름, 사용 테이블
  5) 파일 이름을 누르면 소스 보기가 열리고, 근거가 된 줄을 강조해 보여 줍니다.
  6) [결과 파일 저장]으로 결과를 .json 파일로 남길 수 있습니다.
     다른 PC에서는 첫 화면의 [결과 파일 열기]로 엽니다. (소스 코드는 담지 않습니다)


3. 이번 프로토타입에서 되는 것
------------------------------
  - Java·JSP·Spring MVC(전자정부 표준프레임워크 포함)·MyBatis·iBatis
  - PHP(Laravel, CodeIgniter, 프레임워크 없는 PHP)
  - Go(Gin, Echo, net/http 등)
  - Python(v0.3): Django(urls.py·뷰·템플릿·ORM 모델, DRF API), Flask(Blueprint·Jinja 템플릿·SQLAlchemy),
    FastAPI(APIRouter·SQLAlchemy·SQLModel), DB를 쓰는 Python 배치 스크립트
  - 앱(v0.3): Android(Java·Kotlin의 Activity·Fragment·Compose 화면, 내비게이션·하단 메뉴, Room·SQLite),
    React Native(React Navigation·Expo Router 화면, 탭·드로어 메뉴, sqlite),
    Flutter(라우트·GoRouter 화면, 하단 탭·드로어 메뉴, sqflite·drift), 하이브리드 WebView 화면
  - 앱 화면이 부르는 API(Retrofit·OkHttp·fetch·axios·dio·http)를 같은 폴더의 서버 라우트와 이어
    화면별 사용 테이블까지 보여 줍니다. 앱과 서버가 한 폴더에 있으면 하위 프로젝트로 나눠 표시합니다.
  - DDL(Oracle·MySQL·MariaDB)의 테이블·컬럼·주석
  - 메뉴: 메뉴 데이터 SQL(INSERT), 메뉴 설정 파일, 사이드 메뉴 화면 코드, 앱 내비게이션, 없으면 URL로 추정
  - 배치: 셸·배치·PowerShell·Python 스크립트, crontab, 작업 스케줄러 내보내기(XML), @Scheduled
  - React Native·Flutter 프로젝트의 ios 폴더는 기본으로 뺍니다(iOS 네이티브는 대상 아님).
  - 소스 보기에서 DB 접속 정보(주소·계정·비밀번호)는 ****로 가려 보여 줍니다.


4. 아직 없는 것 (다음 단계)
----------------------------
  - Claude 연동(대화형 이슈 처리, 수정·적용), DB 연결(메뉴 DB 읽기·조회)  ← 다음 버전
  - 형상관리 연동, 작업 이력  ← 다음 버전
  - Excel·HTML 보고서 내보내기
  - JavaScript 서버(Express·NestJS)와 React·Vue 웹 화면 추출 (지금은 언어·기술 판별만)


5. 결과 읽는 법
----------------
  - [추정]: 직접 근거가 없거나 동적 SQL이라 규칙으로 유추한 결과입니다.
  - 신뢰도(높음·보통·낮음): 결과가 맞을 가능성입니다.
  - 확인 필요: 화면과 연결되지 않은 테이블, 메뉴에 없는 화면, 실행 주기를 못 찾은 배치,
    처리 메서드를 못 찾은 URL 등 사람이 확인해야 할 것을 모아 둡니다.

결과가 이상하면 결과 파일(.json)을 보내 주세요. 원인을 찾는 데 도움이 됩니다.
